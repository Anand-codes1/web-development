Some examples of fonts properties in css

colors in css

  1. RGB -> rgb(0,0,0)
  2. RGBA -> rgba(255, 255, 255, 0.445)
  3. HEX CODE -> #000000
  4. HSL -> hsl(0, 0%, 0%)
  5. HSLA -> hsla(0, 0%, 0%, 1)
