Merge css in html

!! There are three way to merge css in html

  1. Inline css

    Inline css means add css on html element and it's work on particular element only

  2. Internal css

    Internal css means add css on html file using style tag inside head tag and it's work on complete html page or element of page

  3. External css

    External css means add css on html file using link tag inside head tag and it's also work on complete html page or element of page
