Some basic selectors in css

  1. tag selector

    - select every same tag once

  2. class selector

    - using ".class_name " "select same tag multiple times

  3. id selector

    - using " #id_name " select one tag only

  4. child selector

    - using " parent > child " you can select any element inside a parent tag if it's avialble directly inside parent tag, not nasted or indirectly

  5. descendant selectors

    - using " parent child" you can select any element inside a parent tag if it's avialble directly or indirectly

  6. universal selector

    -using "*" you can select every element on the page

  7. pseudo selector

    -using ":" pseudo selectors are used to select an element based on its state or position
