Attributes of iFrame

Several attributes can enhance the functionality of an iFrame:

  1. src

    : Specifies the URL of the page to embed.

  2. height and width

    : Define the dimensions.

  3. frameborder

    : Indicates whether to display a border.

  4. scrolling

    : Controls the scrollbars.

  5. name

    : For targeting the iFrame in JavaScript.
